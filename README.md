# Aimigo marketing site (`aimigo.in`)

Static lander deployed to **Cloudflare Pages** project `aimigo`.

Product app lives at **https://chat.aimigo.in**.

```powershell
npx wrangler pages deploy ./marketing --project-name=aimigo --branch=main
```

Also mirrored to GitHub `abhispark/aimigo` when that repo is the Pages Git source.
